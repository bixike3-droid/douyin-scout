# 素材工作区

每个附件保留完整原件。压缩包首先建立完整目录，为图片与视频创建稳定编号和缩略图，再组成联系表逐批查看。联系表批次用于安排模型请求，后面的文件会继续处理。

`attachment_assets` 可按文件名、编号和已识别的画面描述检索全部素材；`attachment_inspect` 可以查看原图、归一化区域或指定秒数的视频帧。已有的总览和相同问题的细看结果会保存，停止后继续时复用完成部分。

附件任务可以持续调用工具。较早的工具消息投影为工作窗口，完整执行过程和证据仍在本地，成员能够再次查询。用户停止、模型服务错误或重复无进展错误会保留当前进度；不会把这些状态写成全部完成。

点击已上传的压缩包可打开素材工作区，查看缩略图网格、搜索素材、打开原图并继续未完成的分析。界面独立显示文件总数、缩略图覆盖、总览覆盖、细看数量和失败数量。视频封面与视频帧观察有明确范围，音轨尚未转写。

官方 DeepSeek 接口的视觉步骤使用 `deepseek-flash`，规划仍使用设置中选定的模型；自定义端点保留自己的模型，也可通过 `llm.vision_model` 指定视觉模型。API Key、端点及用量记录沿用已有配置与审计。
