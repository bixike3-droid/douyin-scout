# 产品定义（草案 · 待拍板）

> 这是产品的"主心骨"：开发、AI 助手、组长之间出现争议时，以这份文件为准。
> 状态：**草案** —— 请逐条过目、修改；确认后删除本行标注，它就是正式版。

## 一句话

源镜是一个**单机桌面工具**：自动采回抖音账号的互动数据，交给 AI 分析，
把"拍什么、为什么"变成有数据依据的传播决策。

## 给谁用

- 目标用户：企业自媒体运营者（当前场景：组长负责的企业账号运营）
- 使用形态：一台 Windows 电脑、一个程序、双击即用
- 明确不是：多用户平台 / SaaS / 任何需要服务器常驻的东西

## 用户的主线流程

1. 首次打开 → 引导：填 DeepSeek Key → 登录抖音（小号）→ 开始第一次采集
2. 采集：完整点赞人名单 → 公开主页与作品 → 全部落地本机归档
3. 分析：互动者画像 / 作品评价 / 下一步计划（DeepSeek，输出为待复核草案）
4. 工作台：查看依据、生成传播方案、人工修改、留档
5. 复盘：历史报告随任务保留，可随时回看

## 不做什么（边界）

- 不做服务器、不做多用户、不做 Web 端（服务器方向已退役）
- 不实现抖音请求签名、不绕过任何技术保护措施
- 不做自动发布 / 自动私信等"代操作"
- 稳定与配额安全优先于速度

## 硬性指标（验收口径）

- 全新电脑：下载 → 双击 → 10 分钟内跑完一次完整流程（当前差距见 [status.md](status.md)）
- 程序内不出现"竹梦村"等历史项目名（产品名待定，见下）
