# 源镜 · 深色任务工作台

2026-10-13，依据用户选定的 A 深色三栏概念图，使用 PySide6 / Qt Widgets 实现原生桌面界面。
项目显示名称为“源镜”；企业资料中的“竹梦村”是当前服务对象。

## 布局与操作

- 顶栏：源镜标识、实际登录态保存状态、数据目录、刷新、登录抖音、最小化/最大化/关闭。
  可拖动空白顶栏移动窗口，双击空白顶栏最大化或还原，右下角可调整尺寸。
- 左栏：新建任务、已有功能导航、企业资料入口和最近的真实传播报告。
  历史条目来自本地报告，复核状态来自保存记录，没有预置虚构任务。
- 中栏：本次需求、四个处理阶段、助手反馈和可展开的资料/作品/建议/复核区域。
  底部输入需求，Enter发送、Shift+Enter换行；该需求会保存并进入模型输入。
- 右栏：内容方案、参考素材、人工稿。选题卡片展示内容提纲、渠道、行动引导、依据及待确认事项。
  缺少素材时显示空位；人工稿保存后，可查看当前保存版本并导出完整决策记录。

## 使用步骤

1. 打开 `dist/打开源镜.lnk`。该快捷方式继续使用原来的 `dist/userdata`。
2. 先用左栏或中栏“企业资料”填写并保存企业特色、推广产品、资料来源。
   已有账号作品需要确认与企业宣传关联；后台指标补录在同一资料窗口内。
3. 顶栏登录抖音，“采集任务”执行采集，“作品数据”查看本人作品与指标。
   配置模型服务仍在“设置”；其他互动资料、历史分析和数据概览入口保留。
4. 点击“新建任务”，输入具体需求并发送。新任务不会自动混入旧报告，也不会因输入为空而发起调用。
5. 处理阶段由实际读取、输入准备、模型调用和报告保存事件驱动。复用缓存时跳过模型调用阶段。
   登录态保存状态不等于已验证的在线连接；数据与模型错误会如实显示。
6. 复核右侧建议，在“人工稿”编辑并填写说明，保存或导出。资料窗口内可关联历史报告记录执行反馈。
7. 左栏历史任务可重新打开已有报告；新建任务保留企业资料与历史数据。

## 对话思考过程

- 发送消息后，等待状态显示在中栏对话流内（"正在思考…"）；对话不再使用右下角进度条。
- 模型思考模式（DeepSeek thinking）返回的思维链**默认折叠**，点击标题行展开、再点收起；流式生成的推理内容实时追加。
- 正文开始生成时标题变为"正在撰写回复…"，完成后变为"思考过程"并保留完整内容。
- 思维链随消息保存在本地（`conversation_messages.reasoning`），历史对话可回看；不进入后续模型上下文。
- 对话使用流式（SSE）；取消会立即中断读取，未完成的思考过程不落库。

## 对话交互细节

- 生成中"发送"按钮原位变为"停止"（■），点击立即中断；已生成的思考过程保留并标注"思考已停止"。
- 悬停消息浮出复制按钮，一键复制正文；出错消息旁固定显示"重试"，直接重发上一条问题。
- 流式生成时聊天自动贴底；向上滚动翻看历史会立即暂停跟随，右下角浮出"↓ 回到底部"按钮，点击平滑回底并恢复跟随。
- 输入框随内容自动伸缩（约1~8 行），发送后收回默认高度。

## 动效与窗口

- 阶段详情展开/收起约190ms，页面切换淡入约170ms，实际处理中状态灯轻量脉冲。
- 操作面板、等待状态与对话刷新以约170ms 淡入出现，不再瞬间跳变。
- “设置 → 交互动效”可关闭动画，偏好保存在当前数据目录的 `desktop-ui.ini`，重启后保留。
- 动效不产生虚假的进度百分比、处理状态或业务成果。
- 原生自绘顶栏使用 Qt 系统移动接口，窗口仍支持最小化、最大化、还原和关闭。
- Windows 上窗口补回系统框架样式：任意边缘/角落可拖拽缩放（系统缩放光标），阴影由系统绘制；最大化/还原与贴边分屏沿用系统行为。状态栏角落的尺寸把手保留作为兜底。
- 窗口或分栏宽度变化时，对话气泡会重新换行并重算高度（不再固定旧尺寸）；主分栏拖拽条加宽到 6px，滚动条加宽到 8px。
- 表格行、页签、展开按钮有悬停反馈；下拉框与数字框获得焦点时边框高亮。
- 同一会话续聊只追加新消息（不再整块重建）；消息正文行距 145%；聊天滚动到底部为约180ms 平滑过渡（流式思考追加时直接跟底）。
- 顶部操作条在操作结束后约 3 秒自动收起；失败信息保留显示。
- 窗口最小尺寸 1060×720，可在 1366×768 屏幕上完整使用。
- 资料与人工稿未保存时退出会提示处理；资料窗口会随主窗口退出关闭。

## 快捷键

- `Ctrl+N` 新建任务；`Ctrl+R` 刷新当前页；`Ctrl+1` 到 `Ctrl+7` 依次切换左侧七个页面。
