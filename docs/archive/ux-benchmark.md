# UX 对标清单（成熟桌面产品的好点子）

2026-10-14 整理。目的：把对标产品里"让体验不僵硬"的具体做法逐条列出，作为源镜的改进池。
"源镜现状"以当前工作区为准；优先级 P0=建议下一批做（收益大、成本可控），P1=值得排期，P2=看需求。

对标对象与获取方式：

- **Cherry Studio**（Electron，52.6k★，中文社区）—— cherry-ai.com
- **Chatbox**（Electron，42k★）—— chatboxai.app
- **Jan**（Tauri，44.9k★，本地优先）—— jan.ai
- **Claude Desktop / ChatGPT Desktop**（官方客户端）—— 思考链与消息交互的"标准答案"
- **WinUI 3 Gallery**（微软官方示例，商店免费）—— Windows 原生手感基准
- **PyQt-Fluent-Widgets Gallery**（PySide6 同技术栈，8.1k★）—— 同样的 Qt 能做出的质感；⚠️ GPLv3/商业授权，只学设计不引代码
- **TablePlus / Linear / Files** —— 表格、动效节奏、列表管理

## 九、明确不抄（边界，防止范围蔓延）

- **主题生态 / 皮肤系统**：维护成本极高，产品只需要一套打磨好的设计。
- **多模型同答 / 模型路由**：当前单供应商 DeepSeek，多模型是复杂度不是价值。
- **Mermaid / LaTeX 渲染**：当前业务（传播方案）用不到。
- **插件市场 / MCP 生态**：范围爆炸，个人开发阶段不碰。
- **全局划词助手**：系统级钩子，杀毒误报风险高。
- **多窗口 / 窗口置顶**：单窗口工作流够用。

## P0 实施进度（共 7 项）

已完成（5 项）：

1. ✅ 生成中"发送 ↔ 停止"按钮：生成中按钮原位变为"停止"，点击立即中断；已生成的思考过程保留并标注"思考已停止"。
2. ✅ 消息悬停工具条（复制部分）：悬停消息浮出复制按钮，写入剪贴板并提示。"重新生成"暂缓——替换式重发需要改造会话协议与存储（当前按追加语义设计），先用"复制 + 失败重试"覆盖主要场景。
3. ✅ 失败消息"重试"按钮：出错消息旁固定显示"重试"，点击自动重发最后一条用户消息。
4. ✅ 滚动跟随策略 + "回到底部"浮标：流式时贴底；向上滚动立即暂停跟随；右下角浮出"↓ 回到底部"，点击平滑回底并恢复跟随。
5. ✅ 输入框高度自适应：随内容在 1~8 行（52~150px）之间伸缩，发送后收回。
