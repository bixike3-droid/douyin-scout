# 采集效率与数据质量

## 操作入口

- 任务记录 → 快速采集：本人作品列表、各作品点赞名单与基础资料。
- 任务记录 → 重点深采：在快速采集基础上，为多作品互动者补充作品，默认每人最多 60 条。
- 互动者 → 补充所选作品：只补充所选对象，默认 12 条，不重新扫描其他人的名单。
- 原有账号资料、通知、点赞人名单、互动者作品的单独采集入口仍保留。
- 强制刷新缓存可重取最新列表；默认依据采集范围、24 小时时效和已知统计变化复用缓存。

快速模式不逐人访问主页，不默认采齐所有互动者的全部作品。
深采优先级来自已确认的不同作品互动数量，未使用粉丝高低、性别或地区排除用户。

## 效率与完成状态

- 默认接口等待间隔 1.5–3 秒，保留抖动、长停顿、配额与熔断。
- 通知面板不作为原生快速流程的必经步骤，仍可手动选用。
- 每页立即归档和入库，记录网络耗时、条目数、下一页游标。
- 每页请求前检查配额、请求后记账，中断后保留已采数据与续采位置。
- 每人作品上限实际生效；增采可接着已保存的采样位置继续。
- 区分已触底、正常为空、采样完成、部分完成和异常。
- 布尔型分页标志与缺失分页标志分别处理，重复游标不会被视为触底。

## 清洗规则

原始记录保留，分析和界面使用可逆的派生视图：

- 同一用户与同一作品的多来源记录合并为一个观察关系。
- 缺少用户 / 作品、非本人作品、陈旧关联不进入当前受众分析。
- 完整扫描确认结束后才标记本次未再观察到的关系；部分采集不据此剔除旧关系。
- 空名单与正数点赞统计冲突时，标记待核验，不能把全部旧观众视为已消失。
- 负数指标在展示与分析中按未知处理，零值保留；原始数值仍可追溯。
- 公开资料缺失、缺少作品样本显示具体理由，不判断为低价值或机器账号。
- 互动者可切换有效、多作品互动、资料待补、暂无样本及原始关联记录。

分析输入补充创作者作品方向、实际互动与质量说明；缺乏公开内容证据时不允许给出确定的契合度评分。
历史报告仍可查看，新评价只使用当前有效互动者的当前版本画像。

## 验证与实测限制

- 测试覆盖采样上限、增采、断点续采、配额、缓存、范围标记、字段未知值和可逆筛选。
- 本轮完整测试 241 项通过，打包程序独立目录启动、自动建库和退出通过。
- 75 条作品的模拟接口中，先采 12 条只需 1 页；补充到 60 条时继续请求 3 页，没有重复关联。
- 本地数据已检查质量视图；不把 0 粉丝 / 无公开作品样本的观众删除。
- 当前登录态单页作品请求实测返回 HTTP 403；持久会话比较未完成身份验证，未证明该接口恢复。
- 本人作品刷新被拒且已有作品时，仅更新已知作品范围，并明确警告新增作品未确认。
- 点赞接口被拒时立即停止后续请求。未实现签名或绕过平台保护。
- 尚无同等数据量下的真实前后耗时对比，不能声称实际采集已快了多少倍。

当前可运行包为 `dist/optimized/douyin-scout.exe`；本机快捷方式继续指向原来的用户数据目录。
