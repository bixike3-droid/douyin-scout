douyin-scout 本地助手
====================

为什么需要它
------------
抖音的登录凭据（sessionid / sid_tt / odin_tt 等）都是 HttpOnly 的，
网页 JS 读不到。而服务器去登录会撞上抖音的验证码墙。

所以登录必须在你自己的电脑上完成 —— 那里是真实用户环境，抖音不会拦。

怎么用
------
1. 双击「启动助手.bat」（第一次会自动装依赖，约 1-2 分钟）
2. 黑色的命令行窗口会一直开着，别关它
3. 回到网页，点「登录我的抖音」
4. 电脑上会弹出抖音，用手机 App 扫码
5. 网页自动变成「已连接」

以后再用
--------
保持那个黑窗口开着就行。关掉 = 断开连接。

隐私
----
- 助手只监听 127.0.0.1，外网访问不到
- 只允许 douyin-scout 的网页调用它（CORS 白名单）
- 登录态直接发给服务器，不经过网页 JS

需要什么
--------
- Windows
- Python 3.11+（https://www.python.org/downloads/，安装时勾选 Add to PATH）
